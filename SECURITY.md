# Security Policy

## Supported Versions

Currently, only the latest version on the `main` branch is actively supported with security updates.

## Reporting a Vulnerability

If you find a security vulnerability:

1. **DO NOT** publish secrets or exploits publicly.
2. **DO NOT** open an issue with sensitive information.
3. Please contact the repository maintainer privately through GitHub (if available) or reach out directly to the core team.

We take all security issues seriously and will respond as quickly as possible to resolve any disclosed vulnerabilities.
